# Сервис для работы С ПВЗ

Сервис предназначен для автоматизации работы сотрудников ПВЗ при приёмке товаров, заказанных через Авито. Он позволяет регистрировать новые ПВЗ, инициировать приёмки товаров, добавлять и удалять товары в рамках приёмки, а также закрывать приёмку. Кроме того, реализована возможность получения сводной информации по приёмкам с фильтрацией по дате.

## Реализация
- Язык разработки: Go
- Работа с БД: 
     - СУБД: PostgreSQl (, Билдер)
     - Драйвер: [pgx](https://github.com/jackc/pgx)
     - Билдер запросов: [squirrel](https://github.com/Masterminds/squirrel)
     - Менеджер транзакций: [go-transaction-manager](https://github.com/avito-tech/go-transaction-manager)
- HTTP API: Сервер работает на порту 8080. Для реализации маршрутизации и обработки HTTP-запросов используется веб-фреймворк [gin](https://github.com/gin-gonic/gin)
- Авторизация и аутентификация: /dummyLogin, который принимает тип пользователя (client или moderator) и возвращает JWT-токен с соответствующим уровнем доступа.
- Автогенерация DTO: [mockery](https://github.com/vektra/mockery)

## Запуск

Есть Makefile со сценариями:
1. Сценарий **test** запуск всех unit-tests
2. Сценарий **compose-up-integration-test** поднимает докер контейнеры, запускает интеграционные тесты 
3. Сценарий **compose-up-all** запуск всего сервиса в докере
4. Сценарий **compose-down** останавливает контейнеры

Если нет **make**, то можно запустить командой:

``` docker compose up --build -d```

## Запросы к сервису
**baseUrl** = "http://localhost:8080/api/v1"

- **POST /dummyLogin**
  
  Получение тестового токена для авторизации.
  
  Тело запроса (JSON):
  ``` 
  {
  "role": "employee" // или "moderator"
  }
  ```

- **POST /pvz**

  Создание нового ПВЗ (пункт выдачи заказов); доступно только для модераторов.

  Тело запроса (JSON):
  ``` 
  {
  // Допустимые значения: "Москва", "Санкт-Петербург", "Казань"
  "city": "Москва" 
  }
  ```

- **GET /pvz**

  Получение списка ПВЗ с возможностью фильтрации по дате приемки и поддержкой пагинации (Для сотрудников и модераторов).

  **query-параметры:** startDate, endDate, page, limit.


- **POST /pvz/{pvzId}/close_last_reception**

  Закрытие последней открытой приемки товаров для конкретного ПВЗ.


- **POST /pvz/{pvzId}/delete_last_product**

  Удаление последнего добавленного товара из текущей приемки по принципу LIFO (доступно только для сотрудников ПВЗ).


- **POST /receptions**

  Создание новой приемки товаров для ПВЗ (доступно только для сотрудников ПВЗ).

  Тело запроса (JSON):
  ``` 
  {
  "pvzId": "uuid-пункта_выдачи"
  }
  ```
- **POST /products**

  Добавление товара в текущую приемку товаров (доступно только для сотрудников ПВЗ).

  Тело запроса (JSON):
  ``` 
  {
  "type": "электроника", // возможные значения: "электроника", "одежда", "обувь"
  "pvzId": "uuid-пункта_выдачи"
  }
  ```
